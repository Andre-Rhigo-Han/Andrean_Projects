# 智能仓储 AGV 路径规划

这是一个基于 C++ 实现的网格路径规划项目，用于在类似仓储环境中为自动导引车（AGV）规划移动路线。

该路径规划器能够为 AGV 计算一条有效的最短路线：机器人从充电站出发，前往目标货架取货，然后到达打包台，同时需要避开障碍物，并满足最大移动步数限制。

## 项目概述

在仓库地图中，每个格子代表可通行区域、障碍物或与任务相关的位置。AGV 必须按照指定顺序完成任务：

```text
起点 / 充电站（S） -> 目标货架（T） -> 终点 / 打包台（E）
```

直接从 `S` 到 `E` 的路线并不代表任务完成，因为机器人必须先访问 `T`。因此，本项目将路径规划问题拆分为两个阶段的最短路径搜索：

1. 搜索从 `S` 到 `T` 的最短路径。
2. 搜索从 `T` 到 `E` 的最短路径。
3. 将两段路径合并为一条完整路线。
4. 检查完整路线长度是否超过机器人的最大步数预算 `K`。
5. 输出路径坐标序列，并在终端中可视化展示路线。

## 功能特点

- **两阶段路径规划**：严格保证任务顺序为 `S -> T -> E`。
- **最短路径搜索**：在无权重网格图上使用广度优先搜索（BFS）。
- **障碍物处理**：将标记为 `1` 的格子视为不可通行区域，并在搜索过程中自动避开。
- **电量 / 步数限制检查**：判断规划出的路线是否在最大允许移动步数内。
- **路径回溯重建**：在 BFS 过程中记录每个节点的前驱节点，到达目标点后还原完整坐标序列。
- **终端可视化**：直接在输入地图上展示规划出的路线。
  - `.` 表示第一阶段路径：`S -> T`
  - `*` 表示第二阶段路径：`T -> E`

## 地图符号说明

| 符号 | 含义 |
|---|---|
| `S` | 起点 / 充电站 |
| `T` | 目标货架 / 取货点 |
| `E` | 终点 / 打包台 |
| `0` | 可通行格子 |
| `1` | 障碍物 |

## 实现思路

本项目使用 C++ 实现，并且只依赖标准库。

### 1. 地图表示

仓库地图使用如下结构存储：

```cpp
vector<string> map;
```

其中，每个字符串表示地图中的一行。这样既能保持存储结构简洁，也可以通过 `map[x][y]` 直接访问任意格子。

核心位置使用简单的 `Point` 结构体表示：

```cpp
struct Point {
    int x, y;
};
```

在读取输入时，程序会扫描整张地图，定位 `S`、`T` 和 `E` 的坐标。

### 2. BFS 最短路径搜索

`bfs(start, end)` 函数负责从指定起点搜索到指定终点的最短路径。

每次 BFS 搜索都会维护以下结构：

```cpp
vector<vector<bool>> visited;
vector<vector<Point>> parent;
queue<Node> q;
```

- `visited` 用于记录已经访问过的格子，避免重复搜索。
- `parent` 用于保存每个格子的前驱位置，方便在找到目标点后回溯路径。
- `queue<Node>` 用于支持 BFS 的层序遍历。

由于地图中每一步移动的代价相同，BFS 可以保证找到无权重网格中的最短路径。

机器人只能向四个方向移动：

```text
上、右、下、左
```

程序会通过辅助函数判断候选位置是否在地图范围内，以及是否不是障碍物。

### 3. 多阶段路径规划

完整路径通过两次 BFS 得到：

```text
path1 = BFS(S, T)
path2 = BFS(T, E)
```

如果任意一段路径不存在，程序会判定当前任务没有可行路线。

如果两段路径都存在，最终路线会通过拼接 `path1` 和 `path2` 得到。由于 `path1` 的最后一个点和 `path2` 的第一个点都是 `T`，合并时会跳过 `path2` 开头重复的 `T` 节点。

### 4. 步数预算检查

在构造完整路线后，程序会检查机器人能否在最大步数预算 `K` 内完成任务。

总移动步数的计算方式为：

```text
完整路线中的坐标点数量 - 1
```

如果路线长度超过最大步数限制，程序会输出 `LOW POWER`，表示电量或步数预算不足。

### 5. 路径可视化

可视化地图基于原始地图副本生成。程序会保留原始任务点标记 `S`、`T` 和 `E`，并只在普通路径格子上添加路线标记：

- `.` 表示从 `S` 到 `T` 的第一阶段路径；
- `*` 表示从 `T` 到 `E` 的第二阶段路径。

这样可以直观地区分“取货路径”和“送货路径”。

## 输入格式

```text
M N K
<第 1 行地图>
<第 2 行地图>
...
<第 M 行地图>
```

其中：

- `M` 表示地图行数。
- `N` 表示地图列数。
- `K` 表示 AGV 支持的最大移动步数。
- 后续 `M` 行表示仓库地图。

## 输出说明

如果存在有效路线，并且满足步数预算，程序会输出：

1. 完整路径坐标序列。
2. 总移动步数。
3. 任务状态。
4. 可视化路径地图。

如果路径规划失败，程序会输出以下信息之一：

| 输出 | 含义 |
|---|---|
| `NO SOLUTION` | 无法到达目标货架，或无法从目标货架到达终点。 |
| `LOW POWER` | 路线存在，但超过最大步数预算。 |

## 复杂度分析

对于一个包含 `M` 行、`N` 列的网格地图：

- 每次 BFS 最多访问每个格子一次。
- 整体路径规划会运行两次 BFS：一次用于 `S -> T`，一次用于 `T -> E`。

因此：

```text
时间复杂度：O(M * N)
空间复杂度：O(M * N)
```

## 编译与运行

使用支持 C++20 的编译器进行编译：

```bash
g++ -Wall -std=c++20 -O2 main.cpp -o main
```

运行程序：

```bash
./main
```

也可以从输入文件读取数据：

```bash
./main < input.txt
```
